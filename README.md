# 🦷 Dental Clinic Registration Form

## Project Description
The Dental Clinic Registration Form is a simple web-based application developed using HTML5 and CSS3. It helps patients enter their personal details, appointment details, and medical information for dental clinic registration.

## Technologies Used
- HTML5
- CSS3
- Visual Studio Code

## Features
- Patient personal information
- Date of birth and gender selection
- Phone number and email validation
- Appointment date and time selection
- Dental treatment selection
- Medical history and allergy details
- Submit and Reset buttons
- Attractive and user-friendly design
- Responsive layout

## Project Structure

Dental-Clinic-Registration/
- index.html
- style.css
- README.md

## How to Run the Project
1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open the index.html file.
4. Run the file using Live Server or a web browser.
5. The Dental Clinic Registration Form will be displayed.

## Output
The webpage displays a patient registration form where users can enter their personal, appointment, and medical details.

## Conclusion
This project demonstrates the use of HTML5 form elements and CSS3 styling properties to create an attractive and user-friendly Dental Clinic Registration Form.
